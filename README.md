# Experiência Prática — Segurança de APIs

## Protegendo APIs no Mundo Real: Segurança, Autenticação e Controle de Acesso

Projeto desenvolvido durante a disciplina de Desenvolvimento Back-end.

### Objetivo

Esta experiência prática tem como objetivo analisar vulnerabilidades de segurança em uma API financeira fictícia e propor mecanismos de proteção para autenticação, autorização e proteção de dados.

### Conteúdos abordados

* Análise de vulnerabilidades em APIs
* SQL Injection e Prepared Statements
* Autenticação e autorização
* JSON Web Token (JWT)
* Middleware de segurança
* Controle de acesso por perfil
* Hash de senhas com bcrypt e salt
* Expiração e proteção de tokens
* Brute force
* Princípios de Confidencialidade, Integridade e Disponibilidade (CIA)

### Observação

Este projeto possui finalidade acadêmica e educacional. Os cenários e exemplos apresentados representam uma API financeira fictícia utilizada para estudo de segurança em aplicações back-end.
